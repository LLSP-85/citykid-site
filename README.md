# citykid-site

Source for [citykidbk.com](https://citykidbk.com) — City Kid, a drop-in toddler classes & events calendar for Ditmas Park, Brooklyn & NYC.

- index.html — the whole site (multi-month calendar, map, filters)
- wrangler.jsonc — Cloudflare Workers config (static assets, routes)
- Pushes to main auto-deploy via Cloudflare Workers Builds.
